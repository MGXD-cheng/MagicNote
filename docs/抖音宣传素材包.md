# Magic Note · 抖音宣传素材包

> 给高三党的低时间成本版本：**一次拍 4 条，一周发完**，不投钱、不开播、不露脸也能做。

---

## 一、发布前的准备（只做一次，约 40 分钟）

### 1. 账号设置
| 项目 | 建议 |
|---|---|
| 昵称 | `XX写代码` / `MagicNote开发者` / `高三做题人机` 这类"人设+身份"组合 |
| 头像 | App 图标，或者你敲代码的键盘照片（真实感更强） |
| 简介 | `高三｜一个人写了一个 App｜MagicNote 作者` + `主页看下载方式` |
| 背景图 | App 截图拼图，或用一句话："没有广告的待办+日记 App" |

> ⚠️ 实名认证需要身份证；**未满 18 岁可以正常发视频，但不能开直播、不能带货、不能开橱窗**。纯做内容分享完全够用。

### 2. 素材准备（很重要，一次录完）
把手机录屏 + 剪映准备好，一次录这几段，能剪出至少 4 条视频：
- 打开 App → 划一遍首页（10 秒）
- 待办：打勾 + 新建（8 秒）
- 日记：写一篇 + 点缩略图看大图（10 秒）
- 桌面小组件：点一下"一句话记录"→ 输入 → AI 分类存好（12 秒，这条最好看）
- 日历：切月份 + 日程专注模式（8 秒）
- 电脑上一段代码滚动（5 秒，用来当"开发者"画面）

**录屏要点**：开飞行模式前一秒再录（避免弹窗）、深色主题更好看、字体调大一点（手机上看小字看不清）。

### 3. 下载入口（抖音不能放外链，必须这样引导）
- **评论区置顶**：`下载：搜 GitHub 搜 MagicNote（仓库里 Releases 有 APK）`
- 简介里写：`GitHub 搜 MagicNote` 或 `主页置顶视频有下载方式`
- 想更方便：把 APK 放网盘（蓝奏云 / 123 云盘），置顶评论写"私信我发你"
- ⚠️ 不要直接写"加微信"，容易被限流；先说"私信"更安全

## 二、四条视频脚本（照着拍就行）

### 第 1 条｜人设开场（最容易起量）
**时长**：18 秒 ｜ **标题**：`高三学生，我用课余时间写了 3 万行代码的 App`

| 时间 | 画面 | 口播 / 字幕 |
|---|---|---|
| 0-3s | 黑屏白字（**钩子，必须狠**） | 字幕：`高三，我做了个 App` |
| 3-8s | 桌面小组件点一下 → AI 分类存好 | "点一下，想到的事就自动进待办或者日记" |
| 8-13s | 快速划过待办 / 日历 / 日记 | "待办、日历、日记、倒数日，全在一块" |
| 13-18s | 电脑代码滚动 + 版本号 | "一个人写的，没有广告，不用登录，数据都在自己手机上" |

**发布文案**：`做了半年，终于敢拿出来见人了 #独立开发 #高三 #宝藏App #安卓`
**置顶评论**：`源码和下载都在 GitHub：MagicNote（可以随意提需求，我基本都会看）`

---

### 第 2 条｜痛点对比（转化最高）
**时长**：20 秒 ｜ **标题**：`为什么我把手机里 5 个 App 都卸载了`

| 时间 | 画面 | 口播 / 字幕 |
|---|---|---|
| 0-3s | 其他 App 的开屏广告（打码）+ 字幕 | 字幕：`打开就 5 秒广告，受够了` |
| 3-9s | 你的 App **秒开** 首页 | "我这个：点开就是内容，没有开屏、没有广告位" |
| 9-15s | 搜索"记账 / 待办"应用商店满屏广告 | "国内应用商店的待办，一半是广告，一半要会员" |
| 15-20s | 数据备份页 / 局域网传输页面 | "数据在你手机里，备份也是你说了算" |

**发布文案**：`无广告无会员 #宝藏App #安卓 #效率工具`

---

### 第 3 条｜功能演示（收藏率最高，容易被搜到）
**时长**：25 秒 ｜ **标题**：`桌面点一下，AI 帮你分类记进待办和日记`

分镜：小组件 → 输入"下周三月考，数学要多刷两道导数题" → AI 判定 → 存进待办 → 再输入"今天和同桌和解了，心里舒服多了" → 自动进日记。
口播重点：**"它自己判断这是事还是心情"**（这句最好卖）

**发布文案**：`AI 一句话整理你的脑子 #AI #效率App #数码`

---

### 第 4 条｜开发者日常（涨粉最快，人味最足）
**时长**：20 秒 ｜ **标题**：`为了一个 Bug，我凌晨两点还在改`

画面：手机 + 电脑同框，代码高亮滚动，打字声（可用剪映音效），最后贴一张"版本历史"截图。
口播：`这个 Bug 是……（讲一个真实的，比如"列表里的数据老是重复导入"），找了三个小时，原来是字符串比较时少了引号判断。`

**发布文案**：`独立开发的日常 #程序员 #代码 #独立开发`

> 这条不用多完美，**真实 + 有点自嘲**就是流量密码。评论区一定有人问"这是什么 App"，这时候再回下载方式。

## 三、发布节奏（高三版，每周只花 2 小时）

| 时间 | 做什么 |
|---|---|
| 周六下午 1 小时 | 一次录完 4 条素材 |
| 周六晚上 1 小时 | 剪 2 条，存草稿 |
| **周五 / 周六 19:00-21:00** | 发 1 条（学生党刷抖音高峰） |
| 下周三晚 | 发第 2 条 |
| 每天固定 10 分钟 | 回评论（**重要！回复会影响推荐**） |

**前 3 秒必须抓住人**：用「数字 + 身份 + 反差」最有效，比如"高三学生""一个人写了半年""3 万行代码""没有广告"。

**看数据只看两个**：
- 3 秒完播率 > 45% → 钩子合格
- 平均播放 > 8 秒 → 内容合格
不合格就换钩子重拍，别改内容。

## 五、三条红线（务必注意）

1. **别夸大**：不要写"最强""干掉某某 App"，容易被举报也招黑；说"我自己用着舒服"最安全。
2. **别碰隐私数据**：视频里不要出现真实姓名、学校、同学信息、真实聊天记录；录屏前清一下通知栏和相册。
3. **别投钱**：高三别花时间研究 DOU+/千川。内容真实+持续更新，自然流量足够。**发完一条就去学习，别看数据**。
