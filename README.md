## ✨ 功能特性

### 📝 待办
- 今日 / 长期双类型，点击即编辑，到期提醒
- 一句话交给 Magic AI 建待办
- **每日打卡**：连续 / 累计天数、鼓励文案、每日提醒，卡片可查看已打卡日期
- **倒数日**：剩余天数，可在日历上标红
- 已完成的待办次日 0 点自动清理（未完成的标注「未完成」）

### 📅 日历
- 日程事件管理，按天查看；月视图按事件真实颜色逐点显示
- 日程提醒（提前 10 分钟 ~ 1 天）
- 时间冲突自动顺延对齐（后一个日程排到冲突结束之后）
- **AI 规划**：填需求 / 现有资源 / 截止时间，自动拆解为可执行方案，一键采纳（日程 + 提醒 + 待办）
- **专注模式**：全屏横屏大字时钟 + 距开始 / 进行中倒计时，屏幕常亮
- 上滑日程列表自动折叠为单周视图

### 📖 日记
- 同一天可记多篇，按时间线合并展示；支持心情标记与本地图片
- 缩略图点击全屏查看：双击放大、双指缩放、拖拽、左右切图
- **日记锁**：数字密码（随机盐 + SHA-256，不存明文）或 指纹 / 人脸 / 设备锁；关闭锁也需验证身份
- **日记自动回复**：写完日记由 Magic AI 以当前人格口吻回复并推送通知
- **AI 笔记**：一句话把聊天记录整理成笔记 → 弹窗预览 → 可提要求重新生成 → 满意后保存到日记（标题前缀「AI笔记：」）

### 🤖 Magic AI
- 对话助手（DeepSeek / OpenAI 及各类兼容端点），历史持久化并标注时间
- 一句话创建 / 修改 / 删除 待办、日程、倒数日、打卡
- 自动注入生活上下文（待办 / 日程 / 日记 / 屏幕时间）做分析与建议
- **Markdown 自动渲染**（设置可开关）
- **聊天记录导出**：可选范围（全选 / 最近 20 条 / 任意勾选）+ 格式（Markdown / `.mgxd` 可导入版）
- **API Key 隐私保护**：密码模式显示 + 小眼睛切换明文
- **获取模型列表**：一键拉取站点可用模型，点选即填

### ⏱ 屏幕时间
- 基于系统 UsageStats 统计使用时长，分类环形图展示
- 日（22:00）/ 周（周日 8:00）AI 报告
- 娱乐超时自动 AI 提醒
- 节能策略：息屏不检查、亮屏 5 分钟一次、无待办不检查

### 💾 数据、同步与隐私
- **`.mgxd` 专属备份格式**（JSON + Base64 图片内嵌，magic=MGXD / version=1.0）
- 选择性导出、导入自动合并（冲突策略：保留两份 / 覆盖 / **跳过重复**）
- 判重规则：**同一类型 + 同一天同一分钟 = 重复项**
- CSV 通用导出
- **局域网同步**：内置 HTTP 服务（ServerSocket，端口 8898），另一台设备浏览器预览 / 下载 `.mgxd`，也能直接下载 App 安装包
- **检查更新**：从 GitHub Releases 获取版本并一键下载安装
- 所有数据仅存本机，不上传

### 🧩 桌面小组件 & 文件关联
- 三个 RemoteViews 小组件：**今日待办**（可直接打勾）/ **倒数日** / **一句话记录**（AI 判断存待办或日记）
- **`.mgxd` 文件关联**：文件管理器 / 浏览器下载里点开即可导入

### 🎨 外观与其他
- 暗色模式（跟随系统 / 浅色 / 深色）
- 功能模块开关（待办 / 日历 / 日记可独立关闭，导航与首页同步隐藏）
- 纯净模式（一键关闭后台保活与全部提醒）

## 📥 下载安装

1. 打开 [**Releases**](https://github.com/MGXD-cheng/MagicNote/releases/latest)，下载最新的 `MagicNote-<版本号>-release.apk`
2. 手机点击安装；若提示「不允许安装未知应用」，在弹窗里允许即可
3. 浏览器提示「可能有害」→ 选「仍然下载」（自签名 APK 的正常提示）

> 需要 **Android 7.0 及以上**。AI 功能需在「设置 → Magic AI 接口配置」填自己的 API Key；不填也能使用全部本地功能。
> 升级安装不会丢数据（签名一致，可直接覆盖）。

## 🛠 技术栈

| 层面 | 选型 |
|---|---|
| UI | Jetpack Compose + Material 3，100% Kotlin |
| 存储 | Room（todos / diaries / events / chat_messages / habits / countdowns）、DataStore 偏好 |
| 导航 | Navigation Compose |
| 网络 | OkHttp + OpenAI 兼容 API（DeepSeek 等），XML/JSON 结构化提示词，前缀缓存友好 |
| 调度 | AlarmManager（含 setAlarmClock）+ 前台服务保活 |
| 构建 | Gradle Kotlin DSL + Version Catalog；R8 混淆与资源压缩 |
| 依赖 | 零第三方 UI 库（环形图、局域网服务、小组件均自实现） |

## 🔨 构建

```bash
./gradlew assembleDebug      # Debug APK
./gradlew assembleRelease    # Release APK（debug keystore 签名）
```

产物位于 `app/build/outputs/apk/`。交付包统一命名 `MagicNote-<版本号>-release.apk`。

---

## ⚙️ 环境备注

- SDK 位于 `/root/Android`；ARM64 环境已内置 aapt2 替换（`setup_android_env.sh`）。
- proot 环境 release 打包需合并 `linked-resources-binary-format` 的 `.ap_` 中间产物再签名。
- 本机 `zipalign` 为 x86-64 二进制无法在 arm64 执行，已通过 `packaging { jniLibs { useLegacyPackaging = true } }` 规避（安装时解压 `.so`，不依赖页对齐）。
